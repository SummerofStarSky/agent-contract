# write · 文档 / 笔记 / 汇报

## 骨架

1. **一句话结论** — ≤40 字。
2. **正文** — 二级标题最多 3 层；每段 ≤5 行。
3. **待确认** — 列出 2–3 处我可能不同意的地方。
4. **自检** — 表格（见 core §5）。

## 硬约束

- 标题层级最多 3 级：`#` / `##` / `###`。
- 不用「综上所述」「众所周知」「值得注意的是」这类套话。
- 每个数据或事实必须带来源；来源不明就标注「待核实」。
- 默认 ≤600 字；超过先给提纲，等我确认再写。
- 一段只讲一件事；段落首句就是结论。

## 例外

- 我说「写长一点」→ 不受 600 字限制，但必须分段并保留骨架。
